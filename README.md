This project creates a RAG-based conversational AI system that can efficiently retrieve and generate accurate responses 
to user inquiries about the MS in Applied Data Science program at the University of Chicago. The system will leverage both textual data 
from the program’s webpage and a pre-trained language model to provide detailed, context-aware answers.
